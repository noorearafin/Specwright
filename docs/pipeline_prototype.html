§6
Same pipeline from the CLI new flags

    
Any scope flag skips the interactive gate — built for CI. Real output from the pushed code:

    
$ python qa_agent.py --list-scopes
Built-in presets:
  smoke           — P0 happy paths only (fastest, for CI gate)
  regression      — P0 + P1, all functional/negative/boundary (nightly)
  security        — Security cases only (run before release)
  accessibility   — Accessibility-only run (before UX review)
  api             — API-target cases only (no browser needed)
  ui              — UI-target cases only (browser flows)
  everything      — All automatable cases (full suite)
Saved scopes (scopes.yaml):
  ci-gate         — priorities=P0, types=functional, limit=15

$ python qa_agent.py prd.md out/ --scope regression --exclude-types boundary --grep login
▶ Scope (from flags): priorities=P0/P1, types=functional/negative/boundary/contract, NOT types=boundary, grep~'login'
▶ Selected 7 cases — 2/5 requirements covered.
  ⚠ No cases selected for: REQ-3, REQ-4, REQ-5

$ python qa_agent.py prd.md out/ --priorities P5
  ⚠ 'P5' in scope['priorities'] matches no case (known priority values: ['P0', 'P1', 'P2'])
  ⚠ This scope selects ZERO cases — nothing would be automated.

$ python qa_agent.py prd.md out/ --requirements REQ-2 REQ-3 --limit 10 --save-scope payments-deep
▶ Scope saved as 'payments-deep' in scopes.yaml
▶ Selected 10 cases — 2/5 requirements covered.

  


  
  

    

      
Scope gate — before

      
    
        
  • 5 presets, or custom = priority / type / target only
    • 
        
  • No way to scope to one requirement or one case
    • 
        
  • Typo in a filter → silently empty suite
    • 
        
  • No warning when a requirement lost all its cases
    • 
        
  • Custom filters rebuilt by hand every session
    • 
        
  • CLI: interactive prompt or all-or-nothing --non-interactive
    • 
      

    

    

      
After — this branch

      
    
        
  • 7 presets (+api, +ui) and 8 combinable filter dimensions
    • 
        
  • requirements, ids, exclude_*, grep, limit, include_manual
    • 
        
  • Validation names the typo and lists the real values
    • 
        
  • Coverage guard: “No cases selected for: REQ-4”
    • 
        
  • Named scopes saved to scopes.yaml — shareable, committable
    • 
        
  • CLI: --scope + 8 filter flags, --save-scope, --list-scopes
    •
